## B.5 ELEMENTS

### B.5.1 Width of Flat Elements and Stiffeners

For flat elements:

a) supported on one edge, the element width $b$ is the distance from the element's unsupported edge to the toe of the fillet or bend at the element's supported edge (Figure B.5.1)

b) supported on both edges and flat elements supported on one edge and with a stiffener on the other edge, the element width $b$ is the distance between the toes of the fillets or bends at the element's supported or stiffened edges (Figures B.5.2 and B.5.3).

c) supported on both edges and with an intermediate stiffener, the element width $b$ is the largest distance between the toe of the fillet or bend at the element's supported edge and the toe of the fillet or bend at the intermediate stiffener (Figure B.5.4).

For all flat elements, if the inside corner radius exceeds 4 times the element thickness, the inside radius shall be assumed equal to 4 times the thickness in calculating $b$.

Dimensions and properties of stiffeners shall be determined in accordance with Figures B.5.3 and B.5.4.

### B.5.2 Radius of Curved Elements

The radius of curved elements $R_c$ shall be taken at the mid-thickness of the element.

### B.5.3 Thickness of Elements

For uniform compression on elements with linearly varying thickness with δ ≤ 2.0:

a) For tapered thickness elements with the thick edge supported and the thin edge free, the slenderness is $(1 - 0.12\delta)(b/t_{avg})$.

b) For tapered thickness elements with the thin edge supported and the thick edge free, the slenderness is $b/t_{avg}$.

c) For tapered thickness elements supported on both edges, the slenderness is $b/t_{avg}$.

where
- $b$ = element width

$$t_{avg} = \frac{t_{max} + t_{min}}{2}$$ (B.5-1)

- $t_{avg}$ = average thickness of the element
- $t_{min}$ = minimum thickness of the tapered thickness element
- $t_{max}$ = maximum thickness of the tapered thickness element

$$\delta = \frac{t_{max} - t_{min}}{t_{min}}$$ (B.5-2)

### B.5.4 Strength of Elements in Uniform Compression

The stress $F_c$ corresponding to the uniform compressive strength of elements is:

For unwelded elements:

$$F_c = F_{cy}$$ (B.5-3)

For welded elements:

$$F_c = F_{cy}(1 - A_{wc}/A_g) + F_{cw} A_{wc}/A_g$$ (B.5-4)

where
- $F_{cy}$ = stress corresponding to the uniform compressive strength calculated using Sections B.5.4.1 through B.5.4.5 for an element if no part of the cross section were weld-affected. Use buckling constants for unwelded metal (Table B.4.1 or Table B.4.2) and $F_{cy}$.
- $F_{cw}$ = stress corresponding to the uniform compressive strength calculated using Sections B.5.4.1 through B.5.4.5 for an element if the entire cross section were weld-affected. Use buckling constants for weld-affected zones (Table B.4.1) and $F_{cw}$. For transversely welded elements with $b/t \leq \lambda_1$, $F_c = F_{cw}$
- $A_{wc}$ = cross sectional area of the weld-affected zone
- $A_g$ = gross cross sectional area of the element.

### B.5.4.1 Flat Elements Supported on One Edge

The stress $F_c$ corresponding to the uniform compressive strength of flat elements supported on one edge is:

| LIMIT STATE | $F_c$ | Slenderness $b/t$ | Slenderness Limits |
|---|---|---|---|
| yielding | $F_{cy}$ | $b/t \leq \lambda_1$ | $\lambda_1 = \frac{B_p - F_{cy}}{5.0D_p}$ |
| inelastic buckling | $B_p - 5.0D_p b/t$ | $\lambda_1 < b/t < \lambda_2$ | |
| in columns whose buckling axis is not an axis of symmetry: | | | |
| elastic buckling | $\frac{\pi^2 E}{(5.0b/t)^2}$ | $b/t \geq \lambda_2$ | $\lambda_2 = \frac{C_c}{5.0}$ |
| in all other columns and all beams: | | | |
| post-buckling | $\frac{k_2\sqrt{B_p E}}{5.0b/t}$ | $b/t \geq \lambda_2$ | $\lambda_2 = \frac{k_1 B_p}{5.0D_p}$ |

### B.5.4.2 Flat Elements Supported on Both Edges

The stress $F_c$ corresponding to the uniform compressive strength of flat elements supported on both edges is:

| LIMIT STATE | $F_c$ | Slenderness $b/t$ | Slenderness Limits |
|---|---|---|---|
| yielding | $F_{cy}$ | $b/t \leq \lambda_1$ | $\lambda_1 = \frac{B_p - F_{cy}}{1.6D_p}$ |
| inelastic buckling | $B_p - 1.6D_p b/t$ | $\lambda_1 < b/t < \lambda_2$ | |
| post-buckling | $\frac{k_2\sqrt{B_p E}}{1.6b/t}$ | $b/t \geq \lambda_2$ | $\lambda_2 = \frac{k_1 B_p}{1.6D_p}$ |

### B.5.4.3 Flat Elements Supported on One Edge and with a Stiffener on the Other Edge

For flat elements

a) supported on one edge and with a stiffener on the other edge,

b) with a stiffener of depth $D_s \leq 0.8b$, where $D_s$ is defined in Figure B.5.3, and

c) with a thickness no greater than the stiffener's thickness, the stress $F_c$ corresponding to the uniform compressive strength is

$$F_c = F_{GT} + (F_{ST} - F_{GT})\rho_{ST}$$ (B.5-5)

where

$F_{GT}$ is determined using Section B.5.4.1 and neglecting the stiffener

$F_{yf}$ is determined using Section B.5.4.2

$\rho_{yf}$ = stiffener effectiveness ratio as follows:

a) $\rho_{yf} = 1.0$ for $b/t \leq \lambda_s/3$ (B.5-6)

b) $\rho_{yf} = \frac{r_y}{9f\left(\frac{b}{t} - \frac{1}{3\lambda_s}\right)} \leq 1.0$ for $\lambda_s/3 < b/t \leq \lambda_s$ (B.5-7)

c) $\rho_{yf} = \frac{r_y}{1.5f\left(\frac{b}{t} + \frac{3}{\lambda_s}\right)} \leq 1.0$ for $\lambda_s < b/t < 2\lambda_s$ (B.5-8)

$r_y$ = the stiffener's radius of gyration about the stiffened element's mid-thickness.

For straight stiffeners of constant thickness (see Figure B.5.3)

$$r_y = \frac{(d_s \sin \theta_s)}{\sqrt{3}}$$

where
- $d_s$ = the stiffener's flat width and
- $\theta_s$ = the angle between the stiffener and the stiffened element.

$$\lambda_y = 1.28\sqrt{\frac{E}{F_y}}$$ (B.5-9)

$F_y$ for the stiffened element determined using Section B.5.4.3 shall not exceed $F_y$ for the stiffener determined using Section B.5.4.1.

For flat elements
- a) supported on one edge and with a stiffener on the other edge, and
- b) with a stiffener of depth $D_s > 0.8b$, where $D_s$ is defined in Figure B.5.3, or with a thickness greater than the stiffener's thickness,

the stress $F_c$ corresponding to the uniform compressive strength is $F_c = F_{1T}$.

### B.5.4.4 Flat Elements Supported on Both Edges and with an Intermediate Stiffener

The stress $F_c$ corresponding to the uniform compressive strength of flat elements supported on both edges and with an intermediate stiffener is:

| LIMIT STATE | $F_c$ | Slenderness<br/>$\lambda_s$ | Slenderness<br/>Limits |
|-------------|-------|-------------|------------|
| yielding | $F_{cy}$ | $\lambda_s \leq \lambda_1$ | $\lambda_1 = \frac{B_t - F_{cy}}{D_t}$ |
| inelastic<br/>buckling | $B_t - D_t \lambda_s$ | $\lambda_1 < \lambda_s < \lambda_2$ | |
| elastic<br/>buckling | $\frac{\pi^2 E}{\lambda_s^2}$ | $\lambda_s \geq \lambda_2$ | $\lambda_2 = C_t$ |

where

$$\lambda_s = 4.62 \frac{b}{t} \sqrt{\frac{1 + A_s I(bt)}{\sqrt{1 + \sqrt{1 + \frac{10.67I_s}{bt^4}}}}}$$ (B.5-10)

- $A_s$ = area of the stiffener only, not including any part of the element stiffened,
- $I_s$ = moment of inertia of a section comprising the stiffener and one half of the width of the adjacent sub-elements and the transition corners between them, taken about the centroidal axis (denoted as o-o in Figure B.5.4) of the section parallel to the stiffened element.
- $b$ = distance between stiffener and supporting element (see Figure B.5.4)
- $t$ = thickness of the flat element supported on both edges (see Figure B.5.4)

$F_c$ shall not exceed $F_c$ determined using Section B.5.4.2 for the sub-elements of the stiffened element, and shall not exceed $F_c$ of the stiffener determined using Section B.5.4.1.

### B.5.4.5 Round Hollow Elements and Curved Elements Supported on Both Edges

The stress $F_c$ corresponding to the uniform compressive strength of round hollow elements and curved elements supported on both edges is:

| LIMIT STATE | $F_c$ | Slenderness<br/>$\lambda$ | Slenderness<br/>Limits |
|-------------|-------|-------------|------------|
| yielding | $F_{cy}$ | $\lambda_s \leq \lambda_1$ | $\lambda_1 = \frac{B_t - F_{cy}}{D_t}$ |
| inelastic<br/>buckling | $B_t - D_t \lambda$ | $\lambda_1 < \lambda < \lambda_2$ | |
| elastic<br/>buckling | $16\lambda^2\left(1 + \frac{\lambda}{35}\right)$ | $\lambda \geq \lambda_2$ | $\lambda_2 = C_t$ |

$$\lambda = \sqrt{\frac{R_o}{t}}$$

For round hollow elements with transverse welds, use of Section B.5.4.5 is limited to elements with $R_o/t < 20$.

### B.5.5 Strength of Elements in Flexural Compression

The stress $F_b$ corresponding to the flexural compressive strength of elements is:

For unwelded elements:

$$F_b = F_{bo}$$ (B.5-12)

For welded elements:

$$F_b = F_{bo}(1 - A_{wc}/A_{ec}) + F_{bw} A_{wc}/A_g$$ (B.5-13)

where

$F_{bo}$ = stress corresponding to the flexural compressive strength calculated using Sections B.5.5.1 through B.5.5.3 for an element if no

part of the cross section were weld-affected. Use buckling constants for unwelded metal (Table B.4.1 or Table B.4.2) and $F_{cy}$.

$F_{bw}$ = stress corresponding to the flexural compressive stress strength calculated using Sections B.5.5.1 through B.5.5.3 for an element if the entire cross section were weld-affected. Use buckling constants for weld-affected zones (Table B.4.1) and $F_{cyw}$.

$A_{wc}$ = cross sectional area of the weld-affected zone in compression

$A_{ec}$ = gross cross sectional area of the element in compression.

### B.5.5.1 Flat Elements Supported on Both Edges

The stress $F_b$ corresponding to the flexural compressive strength of flat elements supported on both edges and flat elements supported on the compression edge with the tension edge free is:

| LIMIT STATE | $F_b$ | Slenderness<br/>$b/t$ | Slenderness<br/>Limits |
|-------------|-------|-----------------------|------------|
| yielding | $1.5F_{cy}$ | $b/t \leq \lambda_1$ | $\lambda_1 = \frac{B_{bc} - 1.5F_c}{mD_{bc}}$ |
| inelastic<br/>buckling | $B_{bc} - mD_{bc} b/t$ | $\lambda_1 < b/t < \lambda_2$ | |
| post-<br/>buckling | $\frac{k_3\sqrt{B_{bc}E}}{(mb/t)}$ | $b/t \geq \lambda_2$ | $\lambda_2 = \frac{k_3 B_{bc}}{mD_{bc}}$ |

$$m = 1.15 + c_x/(2c_t) \text{ for } -1 < c_x/c_t < 1$$
$$m = 1.3(1 - c_x/c_t) \text{ for } c_x/c_t \leq -1$$

$$m = 0.65 \text{ for } c_x = -c_t$$

$c_x$ = distance from neutral axis to the element extreme fiber with the greatest compressive stress

$c_t$ = distance from neutral to other extreme fiber of the element

Distances to compressive fibers are negative and distances to tensile fibers are positive.

### B.5.5.2 Flat Elements Supported on Tension Edge, Compression Edge Free

The stress $F_b$ corresponding to the flexural compressive strength of flat elements supported on the tension edge with the compression edge free is:

| LIMIT<br/>STATE | $F_b$ | Slenderness<br/>$b/t$ | Slenderness<br/>Limits |
|-----------------|-------|-----------------------|------------|
| yielding | $1.5F_{cy}$ | $b/t \leq \lambda_1$ | $\lambda_1 = \frac{B_{bc} - 1.5F_{cy}}{3.5D_{bc}}$ |
| inelastic<br/>buckling | $B_{bc} - 3.5D_{bc} b/t$ | $\lambda_1 < b/t < \lambda_2$ | |
| elastic<br/>buckling | $\frac{\pi^2 E}{(3.5b/t)^2}$ | $b/t \geq \lambda_2$ | $\lambda_2 = \frac{C_{bc}}{3.5}$ |

### B.5.5.3 Flat Elements Supported on Both Edges and with a Longitudinal Stiffener

The stress $F_b$ corresponding to the flexural compressive strength of flat elements supported on both edges and with a longitudinal stiffener located $0.4d_1$ from the compression edge that is in compression is:

| LIMIT<br/>STATE | $F_b$ | Slenderness<br/>$b/t$ | Slenderness<br/>Limits |
|-----------------|-------|-----------------------|------------|
| yielding | $1.5F_{cy}$ | $b/t \leq \lambda_1$ | $\lambda_1 = \frac{B_{bc} - 1.5F_{cy}}{0.29D_{bc}}$ |
| inelastic<br/>buckling | $B_{bc} - 0.29D_{bc} b/t$ | $\lambda_1 < b/t < \lambda_2$ | |
| post-<br/>buckling | $\frac{k_3\sqrt{B_{bc}E}}{(0.29b/t)}$ | $b/t \geq \lambda_2$ | $\lambda_2 = \frac{k_3 B_{bc}}{0.29D_{bc}}$ |

![Figure B.5.5 showing a cross-section diagram of a flat element with a longitudinal stiffener. The diagram shows a rectangular beam section with dimension 'b' for width, 'X' marking a horizontal centerline, '0.4d_1' marking the distance from top to stiffener location, and 'd_1' marking the total distance from neutral axis to compression flange.]

**Figure B.5.5**
**FLAT ELEMENT WITH A**
**LONGITUDINAL STIFFENER**

The moment of inertia of the longitudinal stiffener $I_b$ about the web of the beam shall equal or exceed

$$I_b = \frac{0.02\alpha_s ftb^3}{E}\left[\left(1 + \frac{6A_s}{bt}\right)\left(\frac{s}{b}\right)^2 + 0.4\right]$$ (B.5-14)

where (see Figure B.5.5)

- $A_s$ = cross-sectional area of the longitudinal stiffener
- $d_1$ = distance from the neutral axis to the compression flange
- $f$ = compressive stress at the toe of the flange
- $b$ = clear height of the web
- $s$ = distance between transverse stiffeners
- $t$ = web thickness
- $\alpha_s$ = 1 for a stiffener consisting of equal members on both sides of the web
  - = 3.5 for a stiffener consisting of a member on only one side of the web

For a stiffener consisting of equal members on both sides of the web, the moment of inertia $I_b$ shall be the sum of the moments of inertia about the centerline of the web. For a stiffener consisting of a member on one side of the web only, the moment of inertia $I_b$ shall be taken about the face of the web in contact with the stiffener.

### B.5.5.4 Pipes and Round Tubes

The stress $F_b$ corresponding to the flexural compressive strength of pipes and round tubes is:

| LIMIT STATE | $F_b$ | Slenderness<br/>$\lambda$ | Slenderness<br/>Limits |
|-------------|-------|-----------------------|------------|
| upper<br/>inelastic<br/>buckling | $B_{bt} - D_{bt} \lambda$ | $\lambda \leq \lambda_1$ | $\lambda_1 = C_{bt}$ |
| lower<br/>inelastic<br/>buckling | $B_t - D_t \lambda$ | $\lambda_1 < \lambda < \lambda_2$ | |
| elastic<br/>buckling | $16\lambda^2\left(1 + \frac{\lambda}{35}\right)$ | $\lambda \geq \lambda_2$ | $\lambda_2 = C_t$ |

$$\lambda = \sqrt{\frac{R_o}{t}}$$
