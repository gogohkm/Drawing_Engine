# KDS Building Standards Skill

한국 건축구조기준(KDS) 75개 문서를 검색하고 구조계산을 수행하는 Claude Code 스킬입니다.

## 개요

이 스킬은 **모든 KDS 문서와 이미지 설명을 포함**하고 있어 독립적으로 사용 가능합니다.

### 포함 내용

- ✅ **75개 KDS 문서** (~86,000 lines, ~5.3 MB)
  - 내진설계, 콘크리트, 강구조, 하중, 기초, 가설구조 등
  - 버전: 22.10, 21.02, 24.12 등 최신 기준

- ✅ **206개 이미지 설명** (통합 데이터베이스, ~1 MB)
  - ASCII art 다이어그램
  - 기술 도표, 그래프, 계수표 등
  - 단일 파일 + 앵커 링크로 통합 (파일 수 최적화)

- ✅ **한글↔영문 통합 검색**
  - 메타데이터 기반 빠른 검색 (0.1초)
  - KDS ID, 한글 키워드, 영문 키워드 모두 지원
  - 파일명은 ASCII만 사용 (호환성 100%)

- ✅ **자동화 스크립트**
  - `kds_mapper.py`: 통합 검색
  - 기타 스크립트 추가 가능

- ✅ **참조 가이드**
  - 용어집 (한글-영문)
  - 설계 워크플로우
  - 완전한 메타데이터

## 핵심 특징: 파일명 vs 검색어

### 📁 파일명: ASCII Only (호환성 100%)
```
✅ KDS_41_12_00.md
✅ KDS_41_17_00.md
✅ KDS_14_20_80.md
```
- 모든 OS/도구에서 호환
- ZIP 압축/해제 시 인코딩 이슈 없음
- Git 친화적

### 🔍 검색: 한글/영문 모두 지원 (메타데이터 기반)
```python
# 한글 검색
kds_mapper.py "내진설계"
→ KDS_41_17_00 (건축물 내진설계기준)

# 영문 검색
kds_mapper.py "seismic design"
→ KDS_41_17_00 (Seismic Design Standard for Buildings)

# KDS ID 검색
kds_mapper.py "41-12-00"
→ KDS_41_12_00 (건축물 설계하중 / Building Design Loads)
```

**메타데이터가 모든 정보를 보유:**
- 한글 제목: "건축물 내진설계기준"
- 영문 제목: "Seismic Design Standard for Buildings"
- 버전: "22.10"
- 키워드: ["내진", "지진", "밑면전단력", "seismic", "earthquake"]

## 주요 기능

### 1. 8가지 쿼리 타입 지원

1. **공식 질의** - KDS에서 수식 찾기
2. **계산 질의** - 실제 구조계산 수행
3. **이미지 질의** - 기술 도표 보기
4. **용어 질의** - 한글/영문 용어 설명
5. **비교 질의** - KDS vs 국제기준 비교
6. **관련 기준 질의** - 연관 문서 찾기
7. **기호 질의** - 수식 기호 설명
8. **예제 질의** - 설계 예제 보기

### 2. 빠른 검색 (3-Level Progressive Disclosure)

- **Level 1** (0.1s): 메타데이터 조회
- **Level 2** (0.5s): 참조 파일 확인
- **Level 3** (2-5s): 전체 문서 검색

### 3. KDS 특화 기능

- 한국 지진구역 계수
- SI 단위 (MPa, kN, m)
- 버전 추적 (22.10, 21.02 등)
- 하중조합 (KDS 41 12 00)
- 재료 물성 (콘크리트 fck, 강재 Fy)
