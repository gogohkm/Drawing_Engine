# Abbreviations and Acronyms

Common abbreviations used in GFRP structural design.

## Standards Organizations

| Abbreviation | Full Name |
|--------------|-----------|
| **ASCE** | American Society of Civil Engineers |
| **ASTM** | American Society for Testing and Materials |
| **ACI** | American Concrete Institute |
| **AISC** | American Institute of Steel Construction |
| **AWS** | American Welding Society |
| **ACMA** | American Composites Manufacturers Association |

## Design Methods

| Abbreviation | Full Name | Description |
|--------------|-----------|-------------|
| **LRFD** | Load and Resistance Factor Design | Primary method in ASCE/SEI 74-23 |
| **ASD** | Allowable Stress Design | Alternative method (limited guidance in standard) |
| **FORM** | First-Order Reliability Method | Statistical reliability analysis |

## Materials and Manufacturing

| Abbreviation | Full Name | Description |
|--------------|-----------|-------------|
| **FRP** | Fiber Reinforced Polymer | Generic composite material |
| **GFRP** | Glass Fiber Reinforced Polymer | Glass fiber composites |
| **CFRP** | Carbon Fiber Reinforced Polymer | Carbon fiber composites |
| **AFRP** | Aramid Fiber Reinforced Polymer | Aramid (Kevlar) fiber composites |
| **CSM** | Continuous Strand Mat | Random fiber mat layer |
| **UD** | Unidirectional | Fibers aligned in one direction |
| **DSC** | Differential Scanning Calorimetry | Thermal analysis method |
| **DMA** | Dynamic Mechanical Analysis | Thermal/mechanical testing |

## Directions and Properties

| Abbreviation | Meaning | Description |
|--------------|---------|-------------|
| **L** | Longitudinal | Direction of pultrusion (0°) |
| **T** | Transverse | Perpendicular to pultrusion (90°) |
| **LT** | Longitudinal-Transverse | In-plane shear direction |
| **TT** | Through-Thickness | Perpendicular to L-T plane |
| **COV** | Coefficient of Variation | Standard deviation / mean |
| **$T_g$** | Glass Transition Temperature | Critical temperature threshold |

## Load Types

| Symbol | Load Type | Description |
|--------|-----------|-------------|
| **D** | Dead Load | Permanent gravity loads |
| **L** | Live Load | Variable occupancy loads |
| **$L_r$** | Roof Live Load | Maintenance/worker loads on roof |
| **S** | Snow Load | Snow accumulation |
| **W** | Wind Load | Wind pressure/suction |
| **E** | Earthquake Load | Seismic forces |
| **R** | Rain Load | Rain/ponding loads |
| **F** | Flood Load | Flood hydrostatic forces |
| **T** | Self-Straining | Temperature, settlement effects |

## Seismic Design

| Abbreviation | Full Name | Description |
|--------------|-----------|-------------|
| **SDC** | Seismic Design Category | A through F (risk level) |
| **R** | Response Modification Coefficient | Ductility factor (2.0-3.0 for GFRP) |
| **$C_d$** | Deflection Amplification Factor | Drift magnification |
| **$\Omega_0$** | Overstrength Factor | System overstrength |
| **SFRS** | Seismic Force-Resisting System | Lateral load system |

## Structural Members

| Abbreviation | Full Name |
|--------------|-----------|

## Resistance and Capacity

| Symbol | Meaning | Description |
|--------|---------|-------------|

| **$R_u$** | Required Strength | Factored load demand |
| **TEF** | Time Effect Factor | Same as $\lambda$ |

## Units

### US Customary (Primary in Standard)

| Symbol | Unit | Description |
|--------|------|-------------|
| **ksi** | kips per square inch | Stress (1 ksi = 1000 psi) |
| **kip** | 1000 pounds | Force (1 kip = 1000 lbs) |
| **kip-in** | kip-inches | Moment |
| **in** | inches | Length |
| **in²** | square inches | Area |
| **in⁴** | inches to fourth power | Moment of inertia |
| **ft** | feet | Length (1 ft = 12 in) |
| **°F** | degrees Fahrenheit | Temperature |
| **lb/in³** | pounds per cubic inch | Density |

### SI (in Parentheses)

| Symbol | Unit | Description |
|--------|------|-------------|
| **MPa** | megapascals | Stress (1 MPa ≈ 0.145 ksi) |
| **kN** | kilonewtons | Force (1 kN ≈ 0.225 kip) |
| **kN-mm** | kilonewton-millimeters | Moment |
| **mm** | millimeters | Length |
| **mm²** | square millimeters | Area |
| **mm⁴** | millimeters to fourth power | Moment of inertia |
| **m** | meters | Length |
| **°C** | degrees Celsius | Temperature |
| **kg/m³** | kilograms per cubic meter | Density |

## Common Conversions

| From | To | Factor |
|------|-----|--------|
| ksi | MPa | × 6.895 |
| MPa | ksi | × 0.145 |
| kip | kN | × 4.448 |
| kN | kip | × 0.225 |
| in | mm | × 25.4 |
| mm | in | × 0.0394 |
| °F | °C | (°F - 32) × 5/9 |
| °C | °F | °C × 9/5 + 32 |
