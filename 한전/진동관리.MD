# 대구-44 통로박스 내부 토사작업 진동관리 매뉴얼

## 1. 개요

### 1.1 목적

한국전력공사 계통연계 공사를 위해 대구-44 통로박스(경부고속도로 이정 86.63km) 내부의 토사를 굴착·반출하고, 케이블 관로 설치 후 토사를 원복하는 작업 중 발생하는 **건설진동을 체계적으로 관리**하여 다음을 보장한다:

1. **구조물 안전**: 통로박스 콘크리트 구조물의 균열 확대 및 손상 방지
2. **도로 안전**: 상부 경부고속도로 통행 차량 및 노면 안전 확보
3. **성토체 안정**: 양측 성토 비탈면의 다짐도 저하 및 활동 방지
4. **주변 민원 방지**: 인근 주거·농업시설에 대한 진동영향 최소화
5. **법적 준수**: 소음·진동관리법 등 관련 법규 충족

### 1.2 적용 범위

| 항목 | 내용 |
|------|------|
| 대상 구조물 | 대구-44 통로박스 (7.0m × 4.5m × 41.6m) |
| 작업 내용 | 내부 토사 굴착·반출, 관로 설치, 토사 원복·다짐 |
| 진동 영향권 | 통로박스 구조물, 상부 고속도로, 반경 50m 이내 시설물 |
| 적용 기간 | 토사작업 착수 ~ 원복 완료 |

1. 통로박스 내부 **높이 4.5m** 제한 → 아암 전고 확인

## 4. 진동 예측

### 4.1 예측 방법

FTA 경험식을 사용하여 거리에 따른 PPV를 예측한다:

$$PPV(D) = PPV_{ref} \times \left(\frac{D_{ref}}{D}\right)^{1.5}$$

여기서:
- $PPV_{ref}$: 기준거리 7.5m에서의 참조 PPV (mm/s)
- $D$: 진동원~수진점 거리 (m)
- $D_{ref}$: 기준거리 = 7.5m
- 지수 1.5: 일반 토사지반 감쇠계수

### 4.2 통로박스 구조물에 대한 진동 예측

장비가 통로박스 **내부 바닥 슬래브 위에서** 직접 작동하므로, 바닥 슬래브와 벽체·상부 슬래브로의 진동 전달을 고려한다.

#### 바닥 슬래브 (직접 접촉)

장비에서 바닥 슬래브까지 거리 ≈ 0m (직접 접촉). 이 경우 FTA 경험식의 단순 적용은 비현실적이므로, **장비 접지 진동 수준**을 직접 적용한다.

| 장비 | 바닥 슬래브 PPV (mm/s) | 비고 |
|------|:---------------------:|------|
| 소형 굴삭기 | 2~5 | 굴착 시 충격 포함 |
| 덤프트럭 주행 | 3~8 | 바닥면 요철에 의한 충격 |
| 진동 롤러 | **10~20** | ⚠ 직접 진동 전달 |
| 진동 플레이트 | **8~15** | ⚠ 직접 진동 전달 |

#### 벽체 (바닥에서 전달)

구조물 내부 진동 전달 감쇠: 접합부 1개소당 약 **-3 ~ -6 dB** (약 50~70% 감쇠)

| 장비 | 벽체 PPV (mm/s) | 계산 근거 |
|------|:---------------:|----------|
| 소형 굴삭기 | 1~2.5 | × 0.5 감쇠 |
| 덤프트럭 주행 | 1.5~4 | × 0.5 감쇠 |
| 진동 롤러 | **5~10** | × 0.5 감쇠 |
| 진동 플레이트 | **4~7.5** | × 0.5 감쇠 |

#### 상부 슬래브 (벽체 경유 전달)

바닥→벽체→상부 슬래브: 접합부 2개소 통과 → 약 **25~50%** 수준으로 감쇠

| 장비 | 상부 슬래브 PPV (mm/s) | 계산 근거 |
|------|:---------------------:|----------|
| 소형 굴삭기 | 0.5~1.5 | × 0.25~0.5 |
| 덤프트럭 주행 | 0.8~2.5 | × 0.25~0.5 |
| 진동 롤러 | **2.5~7.5** | × 0.25~0.5 |
| 진동 플레이트 | **2~5** | × 0.25~0.5 |

#### 고속도로 노면 (상부 슬래브 + 토피 2m 통과)

토피 2m에 의한 추가 감쇠: 약 **-6 ~ -10 dB** (약 50~70% 추가 감쇠)

| 장비 | 노면 PPV (mm/s) | 고속도로 영향 |
|------|:---------------:|:----------:|
| 소형 굴삭기 | 0.1~0.5 | 무시 가능 |
| 덤프트럭 주행 | 0.2~0.8 | 무시 가능 |
| 진동 롤러 | **0.6~2.5** | 체감 가능 |
| 진동 플레이트 | **0.5~1.7** | 경미 |

### 4.3 주변 시설물에 대한 진동 예측

통로박스 출구 부근 시설물 (전주, 농업시설) — 최소 이격거리 약 20~30m 가정:

$$PPV(25m) = PPV_{ref} \times \left(\frac{7.5}{25}\right)^{1.5} = PPV_{ref} \times 0.164$$

| 장비 | 25m 지점 PPV (mm/s) | 생활진동 규제 | 판정 |
|------|:------------------:|:-----------:|:----:|
| 소형 굴삭기 | 0.12 | 60 dB(V) | OK |
| 덤프트럭 | 0.32 | 60 dB(V) | OK |
| 진동 롤러 | **0.87** | 60 dB(V) | OK |
| 진동 플레이트 | 0.50 | 60 dB(V) | OK |

> 25m 이상 이격 시 모든 장비의 진동이 생활진동 규제기준 이내

### 4.4 진동 예측 종합

| 수진점 | 최대 예측 PPV (mm/s) | 허용 기준 (mm/s) | 판정 |
|--------|:-------------------:|:---------------:|:----:|
| 바닥 슬래브 | **20** (진동 롤러) | 5 (관리기준) | ⚠ **초과** |
| 벽체 | **10** (진동 롤러) | 5 (관리기준) | ⚠ **초과** |
| 상부 슬래브 | **7.5** (진동 롤러) | 5 (관리기준) | ⚠ **경계** |

## 5. 진동 관리기준값 설정

### 5.1 관리기준값 체계

| **1단계 (주의)** | **3.0 mm/s** | 감시 강화, 작업 방법 점검 | 🟡 황색 |

## 7. 진동 저감 대책

### 7.1 장비 선정 대책

| 대책 | 내용 | 예상 저감효과 |
|------|------|:----------:|
| **저진동 굴삭기** 사용 | 유압 브레이커 대신 유압 크러셔·집게 사용 | 50~70% |
| **소형 다짐장비** 사용 | 대형 진동 롤러 대신 소형 진동 플레이트 사용 | 40~60% |
| **정적 다짐** 병행 | 진동 다짐 + 정적 하중 다짐 (탬핑) 병행 | 60~80% |
| **고무패드 부착** | 무한궤도 장비 → 고무패드 장착 | 20~30% |

### 7.2 시공 방법 대책

#### (1) 다짐 작업 — 핵심 저감 방안

> **다짐 장비가 최대 진동원이므로 다짐 방법이 진동관리의 핵심이다.**

| 방법 | 설명 | 적용 조건 |
|------|------|----------|
| **층별 다짐** | 1회 포설두께 **30cm 이하** → 소형 장비로 다짐 가능 | 전 구간 필수 |
| **물다짐 (수침다짐)** | 살수 후 침투에 의한 자연 다짐 → **무진동** | 모래질 토사에 효과적 |
| **정적 롤러** | 진동 OFF 상태에서 자중 다짐 (무진동 모드) | 진동기준 초과 시 |
| **소형 탬퍼** | 70kg급 이하 소형 탬핑 램머 | 벽체 인접부 |
| **시간대 제한** | 다짐 작업 주간(09~18시)으로 한정 | 전 구간 |

#### (2) 다짐 작업 절차 (진동 관리 포함)

```
[다짐 1회 사이클]

1. 토사 포설 (30cm 이하) ← 소형 굴삭기
         ↓
2. 살수 (적정 함수비 조절) ← 살수차
         ↓
3. 진동 계측 확인 (기준값 이내?)
         ↓ YES              ↓ NO
4a. 소형 플레이트 다짐     4b. 정적 다짐 또는 물다짐
    (PPV 모니터링)              (무진동 방법)
         ↓                      ↓
5. 다짐도 확인 (들밀도 시험)
         ↓ 90% 이상             ↓ 미달
6a. 다음 층 포설 →1      6b. 추가 다짐 →3
```

#### (3) 차량 운행 대책

| 대책 | 내용 |
|------|------|
| **서행 운행** | 통로박스 내부 **10 km/h 이하** |
| **바닥면 정비** | 요철·단차 보수 → 차량 충격 진동 저감 |
| **진입로 정비** | 입구부 경사로 평탄화 |
| **적재량 관리** | 덤프트럭 **적재율 80% 이하** |
| **급제동 금지** | 서행 + 완만 제동 |

#### (4) 시공 순서 대책

| 대책 | 내용 |
|------|------|
| **시험 시공** | 본 작업 전 1개소(5m 구간) 시험 시공 → 실제 PPV 확인 |
| **단계적 시공** | 41.6m를 5~8m 단위로 분할 시공 |
| **교대 작업** | 굴삭과 다짐을 동시에 하지 않음 (진동 중첩 방지) |
| **고속도로 교통 연계** | 필요 시 한국도로공사 협의 → 교통 통제 병행 |

### 7.3 구조물 보호 대책

| 대책 | 내용 |
