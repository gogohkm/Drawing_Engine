## 3. 외부 현황

### 3.1 입구부 전경 (사진 _00, _01, _03)

- 통로박스가 고속도로 **성토체 내부에 완전 매립**되어 있음
- 양측에 **날개벽(Wing Wall)** 설치, 약 45° 각도로 확장
- 상부에 고속도로 **방호벽(난간벽)** 및 가드레일 확인
- 바닥면에 **중앙 배수채널** (콘크리트 측구)이 종단방향으로 설치
- 입구 전면에 잡초·관목 성장 (비포장 통로, 차량 통행 없음)

### 3.2 출구부 전경 (사진 _24, _25, _26)

- 입구부와 유사한 형태의 날개벽 구조
- 우측에 접근도로(포장) 확인, 성토 비탈면을 따라 고속도로까지 연결
- 출구부 콘크리트 표면 상태 양호
- 주변은 농경지·마을 지역 (반농촌 지형)

### 3.3 측면부 (사진 _04, _05, _06)

- 성토 비탈면 경사 약 **1:1.5 ~ 1:1.8**
- 벽체 외측이 토사에 **전체 높이에 걸쳐 접하고 있음**
- 비탈면 표면에 식생(잡초) 피복
- 날개벽이 비탈면 끝단까지 연장

### 3.4 주변 현황 (사진 _08, _13, _23)

- 출구 부근에 **기존 전주(전기·통신)** 확인
- 주변 시설물: 전주, 농업시설, 소규모 건축물
- 접근 도로: 출구측에 포장도로 연결, 입구측은 비포장

## 4. 내부 상태

### 4.1 벽체 (사진 _07, _12)

- 벽체 콘크리트 표면에 **거푸집 이음부(수직 시공이음선)** 명확히 관찰
- 거푸집 타이홀(tie hole) 흔적 규칙적 분포
- **표면 상태**: 전반적 양호, 경미한 백화·수분 흔적
- **균열**: 사진상 벽체에서 **심각한 구조적 균열은 관찰되지 않음**
- 헌치(chamfer) 부위가 벽체-슬래브 접합부에서 확인됨

### 4.2 상부 슬래브 하면 (사진 _12)

- 내부에서 관찰한 상부 슬래브 하면(천장)은 비교적 양호
- 거푸집 자국 및 시공이음부 확인
- 사진상 **뚜렷한 휨 균열은 관찰되지 않음** (조명 제한으로 상세 확인 어려움)

### 4.3 바닥 슬래브 (사진 _09, _10, _11, _14, _16)

#### 시공이음부 상태

- 바닥 슬래브에 **시공이음부(construction joint)** 다수 관찰 (사진 _11, _16)
- 이음부에서 **갈라짐·벌어짐** 확인
- 일부 이음부에 **단차(level difference)** 발생

#### 콘크리트 파손·박리 (사진 _14, _16)

- 바닥 슬래브의 시공이음부 근처에서 **콘크리트 국부 박리(spalling)** 확인
- 사진 _14에서 중앙 배수채널 기부에 **콘크리트 탈락 및 철근 노출** 관찰
- 노출 철근에 **부식(녹)** 확인
- 파손 범위: 국부적 (구조적 심각도보다는 **내구성 저하** 수준)

#### 바닥면 상태

- 바닥 표면에 **토사 퇴적 및 잡초** 성장
- 중앙 배수채널 부근에 잔해물 축적
- 통행 흔적 미미 (차량 비통행 구간)

### 4.4 중앙 배수채널 (사진 _09, _10, _14, _20, _22)

- 바닥 슬래브 위에 콘크리트 측구(배수채널) 설치
- 채널벽 높이: 약 **500mm** (측정 사진 기준)
- 채널벽 상단에 **주황/적색 도색 라인** (시인성 표시)
- 채널벽 기부에 **국부적 파손** 및 일부 세굴 흔적 (사진 _20)
- 채널은 통로박스 전체 연장(41.6m)에 걸쳐 설치

## 6. 측면 토압 검토 판단

### 6.1 현장 조건 분석

사진에서 확인된 통로박스의 매립 조건:

```
        ══════ 경부고속도로 ══════
        ─────── 방호벽/가드레일 ───────
    ╱                                    ╲
   ╱   성토비탈면      토피 ~2.0m    성토비탈면   ╲
  ╱    (양측 토사)    ┌────────┐    (양측 토사)    ╲
 ╱                    │ 상부슬래브 │                    ╲
╱                     │  t=550  │                      ╲
    ← 측면 토압 →     │벽    벽│     ← 측면 토압 →
     p_top=24.2      │체    체│      p_top=24.2
     (kN/m²)         │t=400  │      (kN/m²)
                      │       │
     p_bot=67.0      │ 하부슬래브 │     p_bot=67.0
     (kN/m²)         │  t=550  │     (kN/m²)
                      └────────┘
```

- **구조 형식**: 성토부 폐합 박스 구조 (Closed Box in Embankment)
- **매립 조건**: 양측 벽체 **전체 높이에 걸쳐** 토사 접함 (완전 매립)
- **토사 대칭**: 좌우 대칭 성토 (비탈면 경사 유사)

### 6.2 측면 토압 산정

정지토압계수 $K_0 = 0.5$ (다짐 성토), 토사 단위중량 $\gamma_s = 19\,\text{kN/m}^3$ 적용:

| 위치 | 지표면~깊이 | 정지토압 |
|------|:---------:|:-------:|
| 벽체 상단 | 2.55m (슬래브 0.55 + 토피 2.0) | **24.2 kN/m²** |
| 벽체 하단 | 7.05m (상단 + 벽체 4.5) | **67.0 kN/m²** |
| 평균 | — | **45.6 kN/m²** |

벽체 1m당 측면 토압 합력:

$$P = \frac{(24.2 + 67.0)}{2} \times 4.5 = \mathbf{205.2\,\text{kN/m}}$$

### 6.3 토압이 각 부재에 미치는 영향

#### (1) 벽체 — 직접 하중으로 **중요**

- 벽체는 사다리꼴 토압을 **직접 휨하중**으로 받음
- 벽체 두께 400mm, 수직근 H16@125에 대한 별도 검토 필요
- 골조 모멘트(166.5 kN·m/m)에 토압 모멘트가 **추가**됨

#### (2) 상부슬래브 — 유리하게 작용 (현재 검토에 영향 없음)

- 양측 대칭 토압 → 슬래브에 **축방향 압축력** 도입
- 이 압축력은 슬래브의 휨 내력을 **약간 증가**시키는 효과
- 따라서 현재 슬래브 검토(NG 판정)는 **보수적(안전측)** 결과

#### (3) 하부슬래브 — 유리하게 작용

- 상부슬래브와 동일하게 축압축 도입
- 별도 지반반력 해석 시 함께 검토

### 6.4 판단 결론

| 부재 | 토압 영향 | 현재 검토 결론 변경 여부 |
|------|:--------:|:-------------------:|
| **벽체** | **직접 하중 (필수 검토)** | 별도 검토 추가 필요 |
| 상부슬래브 중앙부 | 유리 (축압축) | **변경 없음** (NG 유지, 보수적) |
| 상부슬래브 지점부 | 경미 | **변경 없음** (OK 유지) |
| 하부슬래브 | 유리 (축압축) | 별도 검토 필요 |

> **결론: 측면 토압은 벽체 설계에서 필수적으로 반영해야 하나, 현재 수행한 상부슬래브 중앙부 휨강도 검토 결론에는 영향을 주지 않는다 (토압이 슬래브에 유리하게 작용하므로 NG 판정이 더욱 보수적임).**

### 7.3 균열 관련 소견

- 사진상 벽체·상부슬래브에서 **뚜렷한 구조적 휨균열은 관찰되지 않음**
- 바닥 슬래브의 이음부 갈라짐은 **시공이음부의 열화**로 판단 (구조적 균열과 구분)
- 철근 노출 부위는 **피복 탈락 → 철근 부식 진행** 단계
- 도로공사 보고 균열에 대해서는 **근접 촬영 사진** 추가 확보 필요 (특히 벽체, 슬래브 하면)

## 8. 한전 공사 관련 현장 여건

### 8.1 케이블 설치 경로

- 통로박스 **좌측 벽체 하부**(바닥 슬래브 위)에 전선관 설치 계획
- 현재 좌측 벽체~배수채널 사이에 **약 3.5m 폭**의 빈 공간 확보
- 바닥면: 비포장(토사 퇴적), 케이블 트레이 설치 전 정리 필요

### 8.2 기존 시설물

- 중앙 **배수채널**(측구)이 전체 연장에 걸쳐 설치 → 한전 설치 공간과 간섭 없음
- 출구 부근 **기존 전주** 확인 → 송전 계통 연결점
- 통로박스 내부에 기존 설비 없음 (빈 상태)

### 8.3 시공 접근성

- **출구측**: 포장 접근도로 있음 → 장비 진입 가능
- **입구측**: 비포장, 잡초 무성 → 정리 후 접근 가능
- 내부: 높이 4.5m, 폭 7.0m → 소형 장비 내부 진입 가능
- 연장 41.6m → 양방향 접근 필요

## 9. 종합 소견

### 9.1 명판에서 확인된 핵심 사실

1. **내공폭 7.0m 공식 확인** → 6m 설계도면과의 불일치 해소 방향 확보
2. **준공 2018년** → 비교적 최근 시공, 7m 전용 설계도면이 반드시 존재
3. **연장 41.6m** → 측량도면과 일치

### 9.2 구조 안전성 관련 판단

| 항목 | 판단 |
|------|------|
| 측면 토압 | 벽체에 필수, 슬래브에는 유리 (현재 검토 변경 없음) |
| 콘크리트 상태 | B등급(양호), 구조적 우려 수준 아님 |
| 균열 | 구조적 균열 미관찰 (추가 정밀조사 권장) |
| 바닥 파손 | 시공이음부 열화 + 배수채널 기부 박리 → 내구성 보수 필요 |

### 9.3 권고사항

1. **7m 규격 준공도면 확보 (최우선)**
   - 명판에서 7.0m × 4.5m 확인되었으므로, 도로공사에 **2018년 준공 당시의 설계변경도면 또는 준공도면** 요청
   - 이 도면에 7m 기준 배근 상세가 포함되어 있을 것

2. **벽체 토압 검토 추가**
   - 양측 완전 매립 조건에서 벽체에 작용하는 사다리꼴 토압(24.2~67.0 kN/m²)에 대한 벽체 구조 검토 필요
   - 벽체 수직근 H16@125의 적정성 확인
