# KDS 용어집 (Korean-English Glossary)

## 기본 용어 (General Terms)

| 한글 | 영문 | 설명 |
|------|------|------|
| 설계기준 | Design Standard | 구조물 설계에 적용되는 기술 기준 |
| 구조설계 | Structural Design | 구조물의 안전성과 사용성을 보장하기 위한 설계 |
| 하중 | Load | 구조물에 작용하는 힘 |
| 강도 | Strength | 재료나 부재가 파괴에 저항하는 능력 |
| 응력 | Stress | 단위면적당 내력 (σ, τ) |
| 변형률 | Strain | 단위길이당 변형 (ε) |
| 처짐 | Deflection | 하중에 의한 변형 |
| 좌굴 | Buckling | 압축부재의 횡방향 휨 파괴 |

## 하중 관련 (Loads)

| 한글 | 영문 | 설명 |
|------|------|------|
| 고정하중 | Dead Load (D) | 구조물 자중 및 고정 설비 하중 |
| 활하중 | Live Load (L) | 사용에 따라 변하는 하중 |
| 풍하중 | Wind Load (W) | 바람에 의한 하중 |
| 적설하중 | Snow Load (S) | 눈에 의한 하중 |
| 지진하중 | Seismic Load (E) | 지진에 의한 하중 |
| 기본풍속 | Basic Wind Speed | 재현기간별 기준 풍속 |
| 지표면조도 | Surface Roughness | 지표면의 거칠기 정도 (A, B, C, D) |
| 노풍도 | Exposure Category | 풍하중 산정을 위한 지형 분류 |

## 내진설계 (Seismic Design)

| 한글 | 영문 | 설명 |
|------|------|------|
| 내진설계 | Seismic Design | 지진에 대한 구조물의 안전성 확보 설계 |
| 밑면전단력 | Base Shear (V) | 구조물 밑면에 작용하는 총 지진력 |
| 응답스펙트럼 | Response Spectrum | 지진동 특성을 나타내는 스펙트럼 |
| 반응수정계수 | Response Modification Coefficient (R) | 비선형 거동을 고려한 설계지진력 저감계수 |
| 지진구역계수 | Seismic Zone Coefficient | 지역별 지진 위험도 계수 |
| 내진등급 | Seismic Design Category | 건축물의 중요도에 따른 내진 등급 |
| 중요도계수 | Importance Factor (I) | 건축물 용도에 따른 가중계수 |
| 설계스펙트럼가속도 | Design Spectral Acceleration (Sₐ) | 설계용 응답스펙트럼 가속도 |

## 콘크리트 구조 (Concrete Structures)

| 한글 | 영문 | 설명 |
|------|------|------|
| 콘크리트 | Concrete | 시멘트, 골재, 물의 혼합체 |
| 철근 | Rebar / Reinforcing Bar | 콘크리트 보강용 강재 |
| 설계기준강도 | Specified Compressive Strength (fck) | 콘크리트의 설계 압축강도 |
| 항복강도 | Yield Strength (fy) | 철근의 항복강도 |
| 휨강도 | Flexural Strength | 휨에 대한 저항 능력 |
| 전단강도 | Shear Strength | 전단에 대한 저항 능력 |
| 압축강도 | Compressive Strength | 압축에 대한 저항 능력 |
| 인장강도 | Tensile Strength | 인장에 대한 저항 능력 |
| 프리스트레스 | Prestress | 미리 가한 응력 |
| 프리캐스트 | Precast | 공장제작 콘크리트 |

| 한글 | 영문 | 설명 |
|------|------|------|

| 유효폭 | Effective Width | 좌굴 고려한 유효 단면폭 |
| 냉간성형 | Cold-Formed | 상온에서 성형한 강재 |
| 용접 | Welding | 열을 이용한 접합 |
| 고력볼트 | High-Strength Bolt | 고강도 볼트 |

## 기초 (Foundations)

| 한글 | 영문 | 설명 |
|------|------|------|
| 기초 | Foundation | 상부구조 하중을 지반에 전달하는 구조 |
| 지반 | Soil / Ground | 기초가 놓이는 땅 |
| 얕은기초 | Shallow Foundation | 독립/복합/전면기초 등 |
| 깊은기초 | Deep Foundation | 말뚝, 피어 등 |
| 지지력 | Bearing Capacity | 지반이 지지할 수 있는 하중 |
| 침하 | Settlement | 하중에 의한 지반의 하강 |
| 액상화 | Liquefaction | 지진 시 지반의 액체화 현상 |
| 옹벽 | Retaining Wall | 흙을 지지하는 벽체 |
