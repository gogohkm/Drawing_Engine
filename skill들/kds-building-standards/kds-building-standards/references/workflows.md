# KDS 설계 워크플로우

## 쿼리 타입별 워크플로우 (8가지)

### 1. 공식 질의 (Formula Query)

**사용자 의도**: KDS에서 특정 공식이나 수식 찾기

**예시 질문**:
- "건축물 내진설계에서 밑면전단력 공식은?"
- "풍하중 계산 공식 알려줘"
- "What is the formula for flexural strength in KDS?"

**워크플로우**:
1. `kds_mapper.py`로 관련 문서 식별
2. 메타데이터에서 `key_formulas` 확인
3. 해당 라인 범위 읽기
4. `glossary.md`에서 변수 정의 추가
5. 공식 + 변수 정의 + KDS 출처 제공

**키워드**: 공식, 수식, formula, equation, calculate

---

### 2. 설계 예제 질의 (Design Example Query)

**사용자 의도**: 단계별 설계 예제 보기

**예시 질문**:
- "철근콘크리트 보 설계 예제"
- "강구조 기둥 설계 과정 보여줘"
- "Show me seismic design example"

**워크플로우**:
1. `kds_mapper.py`로 관련 문서 찾기
2. 문서 내 "예제", "Example", "설계 예" 섹션 검색
3. 단계별 계산 과정 추출
4. 필요시 관련 공식 병행 제공

**키워드**: 예제, example, 설계과정, step-by-step

---

### 3. 계산 질의 (Calculation Query)

**사용자 의도**: 실제 구조계산 수행

**예시 질문**:
- "5층 건물 밑면전단력 계산: 중요도I, 지진구역0.176g"
- "Calculate wind load: height 20m, basic wind speed 30m/s"

**워크플로우**:
1. 공식 찾기 (Formula Query 워크플로우)
2. 재료 물성 / 계수 확인
3. Python 코드 생성 (계산 로직)
4. 실행 및 결과 검증
5. KDS 한계값 확인
6. 결과 + 계산과정 + 근거 제공

**KDS 특화 체크**:
- ✅ 버전 확인 (22.10, 21.02 등)
- ✅ 단위 확인 (MPa, kN, m)
- ✅ 지진구역계수 (한국 특화)
- ✅ 하중조합 (KDS 41 12 00)

**키워드**: 계산, 산정, calculate, compute, determine

---

### 4. 용어 설명 질의 (Terminology Query)

**사용자 의도**: 기술 용어 이해

**예시 질문**:
- "반응수정계수가 뭐야?"
- "What is lateral-torsional buckling?"
- "LRFD와 ASD 차이는?"

**워크플로우**:
1. `glossary.md`에서 용어 검색
2. 없으면 관련 KDS 문서의 "용어의 정의" 절 검색
3. 정의 + 사용 예 + 관련 조항 제공

**키워드**: 뭐야, what is, explain, definition, 의미

---

### 5. 기호/수식 기호 질의 (Symbol Query)

**사용자 의도**: 수식에 사용된 기호 의미

**예시 질문**:
- "fck는 무엇을 의미하나요?"
- "What does R mean in seismic design?"
- "Sₐ 기호 설명해줘"

**워크플로우**:
1. `glossary.md`에서 기호 검색
2. 단위 확인
3. 기호 | 정의 | 단위 | KDS 참조 제공

**흔한 기호들**:
- fck = 콘크리트 설계기준강도 (MPa)
- fy = 철근 항복강도 (MPa)
- V = 밑면전단력 (kN)
- R = 반응수정계수 (무차원)
- Sₐ = 설계스펙트럼가속도 (g)

**키워드**: 기호, symbol, notation, 의미

---

### 6. 이미지/다이어그램 질의 (Image Description Query)

**사용자 의도**: 기술 도표 보기

**예시 질문**:
- "풍력계수 그래프 보여줘"
- "지진구역도 있어?"
- "Show me response spectrum diagram"

**워크플로우**:
1. `kds_mapper.py`로 문서 식별
2. 메타데이터에서 `images` 목록 확인
3. `image_linker.py`로 이미지 설명 읽기
4. ASCII art + 설명 제공
5. 관련 본문 섹션 링크

**키워드**: 그래프, 도표, 그림, diagram, figure, chart

---

### 7. 비교 질의 (Comparison Query)

**사용자 의도**: 기준 간 차이 이해

**예시 질문**:
- "KDS와 IBC의 내진설계 차이는?"
- "LRFD vs ASD 비교"
- "41-12-00과 41-17-00 관계는?"

**워크플로우**:
1. 두 기준/방법 식별
2. 주요 차이점 추출:
   - 설계 철학
   - 주요 계수
   - 하중조합
   - 적용 범위
3. 비교 테이블 형식 제공

**KDS vs 국제기준**:
- 지진하중: 한국 지진구역도 vs ASCE 7 지도
- 풍하중: 한국 기본풍속 vs ASCE 7
- 단위: SI (MPa, kN) 기본

**키워드**: 차이, 비교, difference, compare, vs

---

### 8. 관련 기준 질의 (Related Standards Query)

**사용자 의도**: 연관된 다른 KDS 찾기

**예시 질문**:
- "콘크리트 설계하려면 어떤 KDS를 봐야해?"
- "41-17-00과 관련된 기준은?"
- "What standards are related to seismic design?"

**워크플로우**:
1. `kds_mapper.py`로 문서 조회
2. 메타데이터의 `related_standards` 확인
3. 카테고리별 문서 목록 제공
4. 각 문서의 역할 설명

**예시 관계**:
```
건축물 내진설계 (KDS 41 17 00)
├─ 설계하중 (KDS 41 12 00) - 지진하중 산정
├─ 내진설계 일반 (KDS 17 10 00) - 기본 원칙
├─ 콘크리트 내진 (KDS 14 20 80) - 재료별 상세
└─ 강구조 내진 (KDS 14 31 60) - 재료별 상세
```

**키워드**: 관련, 연관, related, relevant, associated

## 카테고리별 설계 워크플로우

### A. 내진설계 워크플로우

**1단계: 기본 정보 수집**
- 건물 용도 → 중요도계수 (I)
- 건물 위치 → 지진구역계수 (S)
- 건물 높이/층수
- 구조 시스템 → 반응수정계수 (R)

**2단계: 응답스펙트럼 작성**
- KDS 17 10 00 또는 KDS 41 17 00 참조
- 설계스펙트럼가속도 (Sₐ) 산정

**3단계: 밑면전단력 계산**
- V = CₛW
- Cₛ = Sₐ/(R/I)
- W = 유효지진중량

**4단계: 층별 지진력 분배**
- Fₓ = CᵥₓV

**5단계: 재료별 상세설계**
- 콘크리트: KDS 14 20 80
- 강구조: KDS 14 31 60

**참조 문서**:
- KDS 41 17 00 (건축물 내진설계)
- KDS 17 10 00 (내진설계 일반)
- KDS 41 12 00 (설계하중)

---

### B. 풍하중 설계 워크플로우

**1단계: 기본풍속 결정**
- KDS 41 12 00 Table 5.3-1
- 지역별 기본풍속

**2단계: 설계풍속 산정**
- Vz = Vₒ × K_zr × K_zt × I_w

**3단계: 속도압 계산**
- q_z = 0.6 × V_z²

**4단계: 풍압 계산**
- p = q_z × G_f × C_f × C_p

**5단계: 주요부재력 산정**

**참조 문서**:
- KDS 41 12 00 (건축물 설계하중)

---

### C. 콘크리트 구조 설계 워크플로우

**1단계: 재료 선정**
- 콘크리트: fck (MPa)
- 철근: fy (MPa)

**2단계: 하중 산정**
- KDS 41 12 00 참조

**3단계: 부재 해석**
- 휨모멘트, 전단력, 축력

**4단계: 단면 설계**
- 휨: KDS 14 20 20
- 전단: KDS 14 20 22
- 압축: KDS 14 20 20

**5단계: 철근 상세**
### ⚠️ 풍하중 계산 시 중요 주의사항

#### 1. 풍속고도분포계수 K_zr (가장 흔한 실수!)

**올바른 방법:**
```
표 5.5-2 평탄한 지역에 대한 풍속고도분포계수 참조:

지표면조도구분 C의 경우:
- z ≤ z_b (10m):      K_zr = 1.0 (고정값!)
- z_b < z ≤ Z_g:      K_zr = 0.71 × z^0.15

❌ 잘못된 방법: K_zr = (z/Z_g)^α (이 공식은 KDS에 없음!)
```

**핵심 포인트:**
- 단층 건물(H ≤ 10m)은 **K_zr = 1.0 또는 0.81 (조도구분별 고정값)**
- 표 5.5-2를 **직접 읽어야** 함 (계산 공식 아님)
- 공식 0.71 × z^α는 z > z_b일 때만 사용

**조도구분별 z_b와 고정 K_zr:**
| 조도구분 | z_b (m) | z ≤ z_b일 때 K_zr | z > z_b일 때 |
|---------|---------|------------------|-------------|
| A | 20 | 0.58 | 0.22z^0.33 |
| B | 15 | 0.81 | 0.45z^0.22 |
| C | 10 | 1.0  | 0.71z^0.15 |
| D | 5  | 1.13 | 0.98z^0.10 |

#### 2. 박공지붕 정압 발생 확인

**표 5.7-1 주3):**
> "C_pe값이 두 가지일 때는 풍상측지붕이 정압과 부압을 다 받으며,
> 지붕골조는 이 두 가지 조건을 고려하여 설계한다."

**정압 발생 조건:**
- θ ≤ 20° (낮은 경사각)
- H/D ≤ 0.25 (낮은 건물)
- C_pe = 0.0, C_pi = -0.2 조합

**설계 시 체크:**
```python
# 풍상 지붕 검토
W_R_uplift = G_pe × q_H × (-0.5 - 0.0)    # 최대 부압
W_R_down   = G_pe × q_H × (0.0 - (-0.2))  # 최대 정압 (downward)

# 양방향 모두 설계 필요!
```

#### 3. 가스트영향계수 G_pe 주의

**강체 건물 조건 (H/B < 7):**
```
G_pe = 1 + 4 × r_pe × √(B_pe)
```

**유연 건물 조건 (n_R0 × H/V_H < 1.3):**
```
G_pe = 1 + g_pe × r_pe × √(B_pe + R_pe)
```

**확인 필수:**
- 지붕보가 풍향과 평행 vs 직각 → B_pe 공식 다름
- 낮은 건물은 보통 강체 건물 가정

#### 4. 내압계수 C_pi 조합

**표 5.7-4 주의:**
- 밀폐형: 0.0 **또는** -0.2 (둘 다 검토!)
- 부분밀폐형: ±0.55 또는 ±0.70

**설계 시:**
```
최대 uplift:   C_pe - C_pi = -0.5 - 0.0 = -0.5
최대 downward: C_pe - C_pi = 0.0 - (-0.2) = +0.2
```
